12/12、11/12 窗放行，identity 高达 0.61）。若用 v4 周期判决替换 v7b 承担打断，
TTS 会自己打断自己，违背核心需求。当前分工维持：v7b 快触发 + direct_v4 复核
ASR 输入 + TSE 提取；真人 B 误停 TTS 的问题应通过"v7b 触发后引入快速复核再
决定停不停"或重训解决，不能靠删 v7b。另注意：demo `--auto-test` 的"非注册人"
用例实为 SAPI 合成音（v7b 对其不触发 max_p=0.38），不能代表真人 B。

## 测试方法

- **样本**：各测试集 `labels.jsonl` 中含双讲重叠区间（`overlap_frames` 非空）的前 200 条，
  与历史 python 评估（`scripts/eval_pvad.py --e2e`）相同的样本集与选取逻辑
- **管线**：C++ 生产路径（`double_voice --batch-list`，单进程批量，模型只加载一次），
  与 `--wav` 离线模式语义一致：（**每个文件一个全新 Denoise** 的整段预降噪）→ 整段
  fbank+PVAD 预计算 → 逐帧 silero VAD（speech-end 复位门控）→ PvadGate 扫描
  （注：qt_demo auto-test 曾误用跨文件共享的 Denoise 实例导致残态污染，已修为
  每文件新实例，与 CLI/batch 语义一致）
- **enrollment**：`enroll --batch-jsonl` 批量现场注册（CAM++ 一次加载，每条 enrollment
  wav 提 embedding 存 v3 模板），与历史 C++ 评估"每条现场 enroll"语义一致
- **判定**：confirm=2 迟滞（P(target)>0.5 连续 2 帧触发，<0.3 清零）；触发帧落在重叠区
  ±20 帧或触发帧标签为 2 = 正确；未触发 = 漏打断；否则 = 误打断
- **C++ vs python 路径差异注释**：enrollment 走 C++ fbank+CAM++ 现场注册（python 用
  预计算 .npy）、GRU 数值路径、模板仅含正质心（无负模板/cohort 参与 pvad 判决），
  几个百分点的系统性差异属正常

## 与历史 python 评估对照

| 数据 | 漏打断 | 误打断 | 正确率 |
|---|---|---|---|
| python v3 干净（500 条） | 0.6% | 7.0% | 92.4% |

| C++ 双讲 50 条存档（v1 模型，干净） | 2.0% | 10.0% | 88.0% |

简评：

- **v5（离线默认）增广历代最佳**：C++ 增广 84.5%（误打断 15.0%，v4 为 82.5%/16.0%），
  对照 python 89.4%/10.0% 差 −4.9pp（略出 ±3pp 边缘；n=200 时两侧 95% CI 重叠，
  且 v5>v4 的相对排序一致。单 token 回退对照跑为 86.0%/13.0%，说明多 token 在 C++
  路径下未额外获益，差异主要来自数值路径）；干净 95.0% 对照 python 93.0% 差 +2.0pp（线内）。
  v5 行由含 tokens 的 v4 模板驱动（enroll --batch-jsonl 同步产出 tokens）；
- **v4 两条件（历史行）**：干净 97.5%（误打断 4.0%→1.5%）、
  增广 82.5%（误打断 21.6%→16.0%，超过 v2 的 81.8% 参考线），与 python 侧 v4 双优
  （94.0%/83.0%）及另一独立 C++ 复现完全一致，验证默认加载确为 v4；
- 干净条件 v3 C++ 95.5% **高于** python 92.4%（+3.1pp），主要来自误打断更低
  （4.0% vs 7.0%）——路径差异（enrollment 现场注册、数值路径）在正常范围内；
- 增广条件 C++ 79.0% ≈ python 78.2%（+0.8pp），误打断 20.0% vs 21.6%，基本一致；
- v3 在增广上略输 v2 模型（python 对照 78.2% vs 81.8%）的历史结论在本轮 C++ 网格中
  同样成立（79.0% vs v2 的 81.8% 参考线），与"强噪声/混响可试 v2"的模型选择指南一致；
- 两格均明显高于告警线（干净 <85%、增广 <70%），**无异常项**；
- 与 30 条增广抽验（0.800）一致，样本量放大到 200 后结论稳定。

| 0.00 | 97.0% / 12.0% / 18.5% | 95.5% / 13.0% / 21.0% |

负拦截仍高于 v7b），不能照搬官方阈值或直接替换。
