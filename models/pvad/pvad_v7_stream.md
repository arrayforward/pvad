# pvad_v7_stream.onnx — 长流适配版（实验性，未达验收线，勿替换生产）

v7 = v4s 架构不变（FiLM，260,387 参数，state 外置），自 best_v4s.pt 在
data/mixtures_long/（30-90s 事件调度长流 3500 条 + 短句 20% + 纯负 20% +
吸收态正解 30%）上全序列 BPTT 微调 3 epoch（57min/epoch，预算内停训）。
checkpoint models/pvad/best_v7.pt（= best_v7_ep03.pt）。

## 接口
与 pvad_v4_stream.onnx 完全相同：feats_chunk[B,t,80]（EMA α=0.02 CMVN，调用方负责）
+ emb[B,192] + h0[2,B,128] → logits[B,t,3] + hN[2,B,128]。
chunk 对齐 3.58e-06（1/5/50 ✓）；离线 pvad_v7.onnx parity 3.81e-06。

## 结论
长流顽疾（吸收态/纯负假阳）显著缓解，但短句判别大幅退化（长流数据的
标签先验把模型推向保守）。**不替换 pvad_v4_stream.onnx**。下一步：
短句+长流混合分布联合微调（批内 50/50 采样），而非纯长流微调。
